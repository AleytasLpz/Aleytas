ALEYTA'S — V2 NEÓN
==================
Nueva versión visual: fondo oscuro, rosa/fucsia, cian, morado y naranja.
Mantiene nombres de clases principales de la primera versión para facilitar reutilización.

VIDEO DEL HERO
--------------
El inicio busca assets/aleytas-video.mp4.
Coloca tu propio video MP4 con ese nombre. Si no existe, el poster assets/video-poster.svg se muestra como respaldo visual.

DATOS
-----
Edita script.js > SITE_CONFIG: whatsapp, phoneDisplay, email, city, hours y redes sociales.

PRODUCTOS
---------
Edita tienda.html y duplica tarjetas .product para agregar artículos.

PUBLICAR
--------
Sube todo el contenido a public_html o a la carpeta pública de tu hosting. No requiere PHP ni base de datos.
El formulario abre WhatsApp.

IMPORTANTE
----------
Las imágenes, testimonios, precios y datos de contacto incluidos son demostrativos y deben sustituirse antes de publicar.
